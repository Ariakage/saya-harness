## 默认读取与权限边界

默认自动读取和注入由宿主MemoryStore配置控制，读取限于配置根和当前可见作用域。空目录或尚未存在的记忆根按空记忆处理，目录初始化随授权写入流程执行。模型发起的补充读取／检索属于工具调用，Manual Approval对每次调用要求批准。

模型写入和遗忘经过专用可信操作描述。auto先执行配置规则，再进行独立模型核查，不确定时进入人工确认。PLAN仅提供只读接口，Manual Approval对变更工具逐次确认。已知凭据、路径／链接、条目归属、格式与作用域校验在宿主执行。[记忆设计](../../../memory.md)

独立整理草案规定空工具集合与有界JSON候选，后续协调器需要校验来源、预期版本与实际变更schema。当前memory_update按实际持久Session证据建立提案，绑定版本和幂等身份，经授权后提交，记录投影刷新与实际结果。memory_evidence提供原始一基UserText序号／真实call ID、hash和状态，记忆工具输出从独立事实来源中排除。

## 遗忘与保留范围

遗忘请求需要明确目标与范围。来源撤回以该来源支持关系决定受影响内容，明确遗忘事实则覆盖声明范围内的目标及相关派生项。整理过程保留这种操作类型与意图，避免用“仍有旧证据”抵消明确的遗忘要求。

遗忘结果记录已更新的活动记忆、索引、检索缓存、后续上下文和摘要引用，以及仍保留的历史范围。原始会话、历史索引、主题正文和既有导出保留在各自生命周期，备份仅覆盖当前活动视图、来源、遗忘约束和主题引用。接口返回具体覆盖和剩余范围。

当前tombstone与版本水位参与检索、重复提案、恢复、Compact及回滚校验。恢复旧版本或重新引用旧来源时继续执行当前遗忘约束。当前restore／rollback保留墓碑，新增重新启用语义需要独立契约与验证。

## 运行时新增绑定

- 默认根使用 `~/.saya/MEMORY.md` 及 `memory/`，read／inject／write与显式memory-file／preferences-file分别配置。
- `__saya_managed.review`包含宿主核对的最新用户和选中证据、变更前后内容／摘要、scope、revision及截断状态。审核按user_input／succeeded／failed／unknown等级判断。
- goal_summary只保留调用方摘要身份，用户更正和遗忘沿真实用户来源与当前规则判断。旧memory输出、摘要、Hook或插件正文无法制造独立证据。
- 旧记忆请求的实际暴露来源与模型返回hash进入durable记录，失效的完整组先退出请求投影，再供Compact读取。静态英文规则保持缓存前缀，动态版本与来源进入上下文。
- TUI完整review上限64KiB，精确operation ID与revision确认后发布。备份导出绑定审阅时的真实父目录句柄，动态凭据变化重新验证路径和字节。
