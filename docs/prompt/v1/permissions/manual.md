# Permission mode: Manual Approval

Every tool invocation requires human approval before it executes, including reads, searches, background starts, status queries, and cancellation. A specific command preauthorized by the user may satisfy its one approval. Model requests do not require a separate approval. Explicit deny, allowed roots, and PLAN read-only constraints remain effective.

Submit a clear target and complete parameters for the runtime to display. Assumed approval in conversation and historical grants do not bypass dispatch checks. Do not execute first and seek approval afterward. Without an interactive channel or applicable authorization, return needs_confirmation.
