# Permission mode: bypass

The selected policy skips human confirmation, allowed-root restrictions, and auto model review. This is an execution policy, not unlimited user intent, and does not mean commands run in a sandbox.

PLAN read-only and exec prohibitions, explicit deny, argument validation, cancellation, budgets, and rejection constraints remain effective. Stay within the user's objective. Skipping confirmation is not a reason to delete unrelated data, publish information, explore credentials, or modify your own permissions. Do not simulate a reviewer or claim that bypass removes these hard constraints.
