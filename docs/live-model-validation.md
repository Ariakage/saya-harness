可由操作者显式设置 `SAYA_LIVE_API_KEY`，然后使用 [live_protocol_smoke.py](../scripts/live_protocol_smoke.py) 的 `--help` 查看参数，按自己的服务填入模型、三个 API 根地址和上下文窗口后运行。脚本会发出真实请求，可能产生费用；不会启动模型服务，也不会自动从仓库读取凭据。目标 URL 必须由操作者确认，因为凭据会发送到选定服务。
