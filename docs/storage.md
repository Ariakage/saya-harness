# SQLite 存储组件

DEV-022 提供独立的 `SqliteStore`，在调用方指定的数据目录内创建 `sessions.sqlite3`。配置层的默认数据目录为 `$XDG_DATA_HOME/saya`，未设置时为 `~/.local/share/saya`；CLI 接线与目录安全检查仍在 P5 后续任务。新数据库采用私有文件权限，拒绝跟随数据库文件符号链接。

存储组件使用 bundled SQLite、WAL、`synchronous=FULL` 和外键；每批 `StoreChange` 在一个事务中提交，事务失败回滚。会话、完整历史、运行、工具意图／结果、确认请求、显式事件和关键状态变化日志分别保存。事件序号按会话持续递增；逐 token 文本 delta 不写入数据库。状态日志用于恢复与追踪，不等同于 P6 面向外部的完整 JSONL 事件。

保存已知凭据采用失败关闭：调用者提供当前配置引用的秘密值，序列化数据包含已知秘密时拒绝整个事务，不把明文写入数据库或错误信息。完整的全路径脱敏及未知秘密识别不属于此组件当前的验证范围。

当前组件没有跨进程会话锁、崩溃恢复、迁移备份、会话命令或 PLAN 目录冲突检查；这些依次属于 DEV-023 至 DEV-025。内存存储也不会因本组件存在而成为持久存储。完成这些边界之前，普通 CLI 仍使用只读入口，不允许真实工作区写入或命令执行。
