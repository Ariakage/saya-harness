# SQLite 存储组件

`SqliteStore` 在调用方指定的数据目录内创建 `sessions.sqlite3`。配置层的默认数据目录为 `$XDG_DATA_HOME/saya`，未设置时为 `~/.local/share/saya`；CLI 已接入会话创建和查询。新数据库采用私有文件权限，拒绝跟随数据库文件符号链接。

存储组件使用 bundled SQLite、WAL、`synchronous=FULL` 和外键；每批 `StoreChange` 在一个事务中提交，事务失败回滚。会话、完整历史、运行、工具意图／结果、确认请求、显式事件和关键状态变化日志分别保存。事件序号按会话持续递增；逐 token 文本 delta 不写入数据库。状态日志用于恢复与追踪，不等同于 P6 面向外部的完整 JSONL 事件。

保存已知凭据采用失败关闭：调用者提供当前配置引用的秘密值，序列化数据包含已知秘密时拒绝整个事务，不把明文写入数据库或错误信息。完整的全路径脱敏及未知秘密识别不属于此组件当前的验证范围。

会话文件锁通过实际进程竞争及强制终止测试；不同会话可并行运行，查询不要求会话锁。数据库初始化也通过独立文件锁串行化。会话模式或工作区变更前先同步保守的安全检查点，变更事务完成后收敛为当前状态；崩溃时检查点保留所有可能位置，恢复前先检查 PLAN 目录，再打开数据库。旧会话若没有检查点，非空 WAL 使用校验帧和滚动校验和的内存快照，不创建或修改 SQLite 附加文件。旧会话快照的数据库文件和 WAL 各上限 512 MiB，超出时明确报错；正常新会话依赖小型检查点，不受此预检上限影响。

内部 schema 当前为 2。识别版本 1 后先通过 SQLite 在线备份生成独立文件、检查并同步到磁盘，再通过事务新增会话更新时间索引和更新版本；迁移失败保留原库与备份。版本更高或库损坏时拒绝打开。中断恢复将运行中的工具标记为 `unknown`，保留已保存的结果并原子补齐悬空协议消息；确认和输入中断不恢复授权，也不重放。后台启动意图先持久化，子任务使用可关联的标识，执行前保存子工具意图、执行后保存结果；会话详情可列出后台状态。恢复不重放任务，无法确认的结果标记为 `unknown`。强制终止 Saya 后后台子进程可能继续运行，未知状态不表示进程已停止；正常结束则等待清理。内存存储不会因本组件存在而成为持久存储。
