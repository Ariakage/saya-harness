# CLI MVP 实施任务

**状态：任务定义已准备；实际任务状态见[开发进度](progress.md)。**

本文件细化完整基线 B-23 的实施顺序，任务范围以[完整基线](mvp-baseline.md)为准。阶段退出条件和估算见[路线图](roadmap.md)，实际状态只在[开发进度](progress.md)维护；任务出现在这里不代表已完成。

依赖列是最小任务依赖，默认仍按 P0→P7 集成。每个任务提交聚焦的实现与相称验证；内部 Rust 类型和模块拆分由实现者处理，不重新选择产品需求。

## P5 持久化与恢复

| 任务 | 内容 | 依赖 | 交付与验证 |
| --- | --- | --- | --- |

| DEV-024 | 跨进程会话写锁、迁移备份、schema 兼容与损坏处理 | DEV-022、DEV-023 | 真正的两个进程竞争只允许一个写入者；查询仍可读；高版本拒写、迁移失败不丢原库 |
| DEV-025 | 保存失败／崩溃／unknown／悬空工具与 PLAN 数据目录冲突 | DEV-008、DEV-009、DEV-012、DEV-022、DEV-023、DEV-024 | 故障注入证明不在意图保存失败后执行；已执行结果不明不自动重跑；历史协议记录闭合；工作区保持不变 |

必须区分“曾请求／曾确认”“已经执行”和“结果不明”。把历史消息回传给模型不等于重新执行工具；任何恢复补全都不能产生旧操作的副作用。
