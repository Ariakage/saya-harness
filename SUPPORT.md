# Support / 获取支持

[中文](#获取支持)

## Check the docs first

Most usage and development questions are already covered:

- [README.md](README.md): quick start, configuration, installation
- [docs/usage.md](docs/usage.md): CLI usage guide
- [docs/configuration.md](docs/configuration.md): configuration reference
- [docs/development.md](docs/development.md): development workflow and `just` tasks
- Other topic docs under [docs/](docs/) (sandbox, MCP, modes, etc.)

## Questions and feedback

- **Usage questions / general discussion**: open an [Issue](https://github.com/Ariakage/soyo-harness/issues) describing your environment (`soyo --version`, OS and architecture) and what you have tried.
- **Bugs**: use the [Bug Report](https://github.com/Ariakage/soyo-harness/issues/new?template=bug_report.yml) form.
- **Feature requests**: use the [Feature Request](https://github.com/Ariakage/soyo-harness/issues/new?template=feature_request.yml) form.
- **Security issues**: use the private channel in [SECURITY.md](SECURITY.md); do not disclose publicly.

## Notes

- This project is maintained by a very small team; response time is not guaranteed. Complete environment info and a minimal reproduction significantly speed things up.
- Redact logs and configs before pasting: remove API keys, tokens, and personal paths. Credentials should only ever be referenced via environment variables.
- Issues in either Chinese or English are fine.

# 获取支持

## 文档优先

大多数使用与开发问题已有文档覆盖，提问前请先查阅：

- [README.md](README.md)：快速上手、配置与安装
- [docs/usage.md](docs/usage.md)：CLI 使用指南
- [docs/configuration.md](docs/configuration.md)：配置项说明
- [docs/development.md](docs/development.md)：开发流程与 `just` 任务
- [docs/](docs/) 目录下的其他专题文档（沙箱、MCP、工作模式等）

## 提问与反馈

- **使用问题 / 一般讨论**：开 [Issue](https://github.com/Ariakage/soyo-harness/issues)，说明你的环境（`soyo --version`、操作系统与架构）和已尝试的步骤。
- **Bug**：使用 [Bug 报告](https://github.com/Ariakage/soyo-harness/issues/new?template=bug_report.yml) 模板。
- **功能建议**：使用 [功能建议](https://github.com/Ariakage/soyo-harness/issues/new?template=feature_request.yml) 模板。
- **安全问题**：请走 [SECURITY.md](SECURITY.md) 的私密渠道，不要公开披露。

## 注意事项

- 这是一个个人/小团队维护的项目，回复时间不作承诺；提供完整环境信息与最小复现可显著加快处理。
- 贴日志或配置前请脱敏：移除 API Key、令牌、路径中的个人信息。凭据本身只应通过环境变量引用。
- Issue 主要使用中文或英文均可。
