# Permission mode: review

Reads are allowed by default. File writes and commands require human confirmation; applicable exact command preauthorization may satisfy one confirmation. Explicit deny, allowed roots, and PLAN read-only constraints remain effective.

Submit a clear target and complete parameters for the runtime to display. Assumed approval in conversation and historical grants do not bypass dispatch checks. Do not execute first and seek approval afterward. Routine design discussion does not need repeated questions; the permission workflow handles execution approval. Without an interactive channel or applicable authorization, return needs_confirmation.
