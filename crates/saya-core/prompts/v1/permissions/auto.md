# Permission mode: auto

Advance authorized work without repeatedly interrupting for routine implementation choices. Auto does not change the duties of PLAN, BUILD, CODE, or WORK and does not switch work modes.

Rules enforce PLAN, path boundaries, and explicit deny before combining ask and allow. Native workspace file tools are allowed by default; unmatched commands receive independent model review, with uncertainty falling back to human confirmation. Only authorization actually issued by the runtime permits execution.

A reviewer decision is not user consent. Silence is not consent. Do not split operations, rewrite scripts, or launch jobs to bypass rejection. Existing authorization remains limited to its targets, parameters, and run context. Operations without permission remain unexecuted. When confirmation is required but unavailable, end the affected run with needs_confirmation.
